# RETRAC TWEAKS

⚡ **Windows gaming optimization toolkit**

Retrac Tweaks is a Windows optimization application designed to provide simple, reversible gaming-related system tweaks.

## 🚀 Features

### ⚡ FPS Tweaks
- Windows Game Mode
- Disable Game DVR
- Disable Background Recording
- Simple Apply / Undo controls

### 🌐 Network
Network optimization tools are being developed.

### 🪟 Windows
Additional Windows optimization tools are being developed.

## 💻 Requirements

- Windows 10 or Windows 11
- 64-bit Windows
- Retrac Tweaks `.exe`

## 📥 Download

Download the latest **RetracTweaksApp.exe** from the Releases section.

## ⚠️ Important

Retrac Tweaks changes Windows settings. Results can vary depending on your PC and configuration.

The tweaks do not guarantee higher FPS or lower network latency.

Always keep a backup of important files before making system changes.
